# MotoNav iOS 0.15.2

专辑封面「查不到」修复版。固件无需更新（v7.12.9-photo.5 及任意支持 bulk type 5 的版本均可）。

## 修复

0.15.0 装上后音乐页仍只显示内置黑胶占位图，原因是封面查询压根没拿到图：

- **iTunes 中国区已无曲库**：`https://itunes.apple.com/search?...&country=CN&entity=song` 对中文歌曲返回 0 条。改为依次尝试 `us` / `jp` / `tw`；同名歌曲先用「歌名+歌手」、再用「仅歌名」两种关键词搜索。
- **歌手名中英不一致导致结果被全部过滤**：iTunes 元数据里是 `Eason Chan` / `Mao Bu Yi`，AMS 传来的却是「陈奕迅」/「毛不易」。现在歌手只作为排序加分，不再硬过滤；歌名匹配也改为归一化比对（去掉括号版本说明、Live / Remix / 伴奏等后缀）。
- **完全匹配不上时给近似封面**：退回搜索结果里第一张可用封面，总比黑胶占位强，状态里会标注「近似」。
- **失败也能重试**：去重冷却从「成功失败一律 10 分钟」缩短到 30 秒；`refresh(force:)` 会强制重查。
- **封面下载兜底**：300×300 图取不到时退回 100×100 原图。
- **可诊断**：App「调试信息」里新增一行 `专辑封面：...`，会显示「未触发（等待歌曲信息）」「查询中」「未找到封面」「iTunes(us) 精确 ✓ 已发送 78 KB」等状态，一眼定位卡在哪一段。

## 功能

- **专辑封面**（CoverArt.swift）：优先 Apple Music 本地封面，其次 iTunes Search API；居中裁方 200×200 RGB565，经 bulk type 5 发给圆屏，收满自动切换显示。
- **导航播报静音**（MotoNavApp.swift）：监听 `T,V` 命令，翻转静音并立即停止当前播报，与圆屏 PWR 大键联动，音乐播放不受影响。

## 说明

- 高德 Key 不内置，首次打开在「Key 设置」里填自己的 Key（Bundle ID 见 App 内一键复制）。
- 本版本为未签名 IPA，用 Sideloadly + 自己的 Apple ID 签名安装，免费账号 7 天过期。
- 升级安装会覆盖同 Bundle ID 的 0.15.0；若安装失败，先卸载旧版再装。
- 若调试信息显示「无歌曲信息」，说明 AMS/HID 元数据没到，需在 iPhone 蓝牙设置里完成与圆屏的配对，并确认音乐页能显示歌名。
